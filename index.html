Computer Vocabulary Study Guide Reference

Core Hardware Components

  • Keyboard: Device that enters data with letters, numbers, symbols, and special function keys.
  • Monitor: An electronic visual display for computers.
  • Tower: A desktop system unit housing all of the computer's components.
  • Mouse: A hand-operated electronic device that controls the coordinates of a cursor on your computer screen.
  • Track Pad: The small area at the bottom of a laptop that allows you to move, select, and change items using your finger.
  • Circuit Board: An insulated board on which microchips and other components are mounted or etched.
  • Processor (CPU): Central Processing Unit; interprets and carries out basic instructions.
  • RAM: Random Access Memory; temporary storage for active programs, erased when power is off.
  • Microchip: Miniature electronic circuit used to control computers; also called microprocessor.
  • Hardware: The physical parts of the computer you can actually touch.

Input, Output, Ports & Storage

  • Input: Entering data into the computer. (e.g. Keyboard, mouse, trackpad, microphone, webcam, scanner).
  • Output: Data the computer gives to you. (e.g. Monitor, printer, speakers, headphones).
  • Ports: Connects external devices to system unit. Color-coded. (e.g. USB, HDMI, Ethernet, VGA, DVI, eSATA, Aux jack, S-video, DisplayPort, Power port).
  • Storage: Flash drive, SD card, CD/DVD, floppy disk, external/internal hard drive, Cloud, Google Drive, Amazon Photos, Pogo Plug.

Software & Security

  • Software: Applications that tell hardware what to do and how to do it (programs, games).
  • Operating System (OS): Most important program that lets hardware and software work together.
  • Virus: Malicious program written to alter operation, damage devices, or steal data.
  • Antivirus: Software used to prevent, scan, detect, and delete malicious code.
